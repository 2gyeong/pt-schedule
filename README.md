# PT 스케줄 관리

여러 PT 트레이너가 각자 가입해서 쓰는 회원 일정 관리 웹앱.

## 실행 방법

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# .env에서 SECRET_KEY, ADMIN_NAME, ADMIN_PASSWORD 값을 원하는 값으로 수정

python run.py
```

브라우저에서 http://127.0.0.1:8000 접속.
(macOS의 AirPlay 수신 기능이 5000번 포트를 함께 사용해서 충돌이 나기 때문에 8000번 포트를 씁니다.)

## 계정 구조

- **관리자**: `.env`의 `ADMIN_NAME`/`ADMIN_PASSWORD`로 서버 시작 시 자동 생성됨. `/admin`에서 트레이너 가입 승인/거절, "이 트레이너로 보기"로 특정 트레이너의 화면(회원/일정/지점 등)을 그대로 조회·수정 가능.
- **트레이너**: 로그인 화면의 "회원가입"에서 이름/비밀번호/비밀번호 확인만으로 가입 신청 → 관리자 승인 후 이름+비밀번호로 로그인. 각 트레이너의 회원/일정/지점 데이터는 서로 완전히 격리됨.

## 사용 순서

### 기본 (개별 등록/요청)
1. 트레이너로 로그인 (또는 관리자가 해당 트레이너로 "보기" 진입)
2. "지점 관리"에서 지점 등록 (이름 + 위도/경도)
3. "회원 관리"에서 회원 등록 (기본 지점 + 구매한 PT 횟수 지정) → 회원별 예약 링크 확인, 잔여 횟수는 목록에서 언제든 +/- 조정 가능
4. "달력"에서 날짜 클릭 → 회원/지점 선택 후 일정 직접 등록, 또는 회원이 자기 링크로 즉시 요청 → 개별 승인/거절
   (회원 링크로 들어간 페이지는 트레이너 메뉴가 전혀 보이지 않는 별도 화면입니다)

### 다지점 일괄 스케줄링 (여러 회원을 한 번에 최적 배치)
1. "가능 시간"에서 선생님의 매주 반복 가능 시간을 블록 그리드로 클릭/드래그해서 저장 (언제든 수정 가능)
2. 회원들도 각자 링크로 접속해 "내 고정 가능 시간" 그리드에 매주 반복 가능한 시간을 저장 (선생님이 가능한 시간 밖은 회색으로 막혀서 선택 불가)
3. "스케줄링 라운드"에서 새 라운드 생성 (배정할 기간의 시작일/종료일, 세션 길이)
4. 라운드 상세 페이지에서 회원마다 "이번 라운드 횟수"를 입력 (잔여 횟수보다 많이 넣어도 잔여 횟수만큼만 배정) → "스케줄 생성" 클릭 → 선생님과 회원의 고정 가능 시간이 겹치는 구간 안에서, 이동거리(직선거리 기준)를 최소화하는 방향으로 자동 배정
5. 달력에서 생성된 제안(주황색)을 확인/수정하고, 라운드 상세에서 "라운드 승인"으로 일괄 확정 → 이때 회원별 잔여 횟수가 배정된 만큼 차감됨
6. 회원은 자기 링크에서 확정된 예약을 확인 가능
7. 새로 추가되는 회원이나 급한 일정은 라운드와 무관하게 "달력"에서 트레이너가 직접 등록하거나, 회원이 "급하게 개별 요청하기"로 신청 (전체 재계산 없음)
